# Fundación Entrelineas

Este es el repositorio de la Fundación Entrelineas, un proyecto desarrollado con Astro.

## Estructura del Proyecto

- `public/`: Archivos estáticos.
- `src/`: Código fuente del proyecto (componentes, layouts, páginas).
- `astro.config.mjs`: Configuración de Astro.
- `package.json`: Dependencias y scripts.

## Comandos Principales

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Construir para producción
npm run build

# Previsualizar la construcción localmente
npm run preview
```

Para más información, visita la [documentación de Astro](https://docs.astro.build/).
